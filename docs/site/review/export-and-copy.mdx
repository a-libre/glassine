## Export as PDF

⌘⇧E, or File → Export as PDF…, or the ⌘K command bar. A save dialog asks where; the result is a paginated PDF with selectable text, laid out in whichever [Review](/review/review) style is current. Pick the style first if it matters — Book for something to print, GitHub for something plain.

PDF is the only export. The files are plain Markdown, so for anything else — Word, HTML, EPUB — any converter works on them directly; the [files page](/library/files) says where they are.

## Copy the whole document

**⌘⇧C copies it as Markdown**, exactly as it is in the file.

**⌥⌘C copies it as rich text.** RTF and HTML both go on the clipboard, so Mail, Notes, Slack, Google Docs and Word keep the headings, bold, lists and links when you paste.

The copy button at the bottom-right of the editor does Markdown on a click, with rich text one click-and-hold away, and both are in the right-click menus in the sidebar and All Documents, so you can copy a document without opening it.
