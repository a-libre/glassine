All of it is in Settings → Editor, under *Type* and *Layout*, and all of it is live in the window behind the settings card.

## Type

| Setting | Default | Range |
|---|---|---|
| Font | Helvetica Neue | Every family installed on the Mac, plus the system faces at the top of the list: New York (system serif), San Francisco (system), SF Rounded, SF Mono |
| Size | 16 pt | 11–32 pt, also ⌘+ / ⌘− / ⌘0 |
| Line height | 1.55× | 1.0–2.2× |
| Paragraph spacing | 0.65 em | 0–1.5 em |
| Letter spacing | 0 pt | −1 to 2 pt |
| Larger headings | On | H1 at 1.5× the body size, H2 at 1.25×, H3 at 1.1×; off, every heading keeps the body size and shows only as bold |
| Center headings | On | In the editor and in Review |

## Layout

| Setting | Default | Range |
|---|---|---|
| Column width | 660 pt | 420–1100 pt. The text sits in a centered column of this width; a narrower window narrows the column with it |
| Top margin | 96 pt | 24–240 pt. The space above the first line. Typewriter scrolling takes over this space while it is on |

The sidebar's width is set by dragging its edge and remembered.

## Review

Review has its own scale, ⌘+ and ⌘− while a page is showing, from 60% to 200%; ⌘0 returns to 100%. Each Review style brings its own typography — Book's serif and drop caps, Mono's monospace — and does not follow the editor's font.
