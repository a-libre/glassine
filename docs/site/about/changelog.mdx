Glassine moves in days rather than versions so far. Version 0.2.8 (build 16, September 11, 2026) is the direct download; 0.2.3 (17), the build in App Review, has the same code without the updater. Both hold everything below, including the lines marked *after build 7*, which went in after the earlier store build of that number. Everything here is in the source on `main`.

<Update label="September 5, 2026">
- Date chips draw as one capsule again. A token whose `@` is dimmer than its date could reach the layout manager as two runs, each drawing its own capsule, overlapping.
- The Today view is now **Timelapse**, in the sidebar, the View menu, the command bar, the shortcut sheet and here.
- **⌘1, ⌘2 and ⌘3** open the three rows at the top of the sidebar in order: All Documents, Timelapse, New Document. ⌘P, ⌘D and ⌘N still work. The rows are reordered to match and show the numbers.
- Gallery cards animate their own entrance, so a mosaic removed mid-cascade can no longer leave a ghost behind.
- Timelapse: every day is the same size whatever it holds, each fades out at its lower edge before it reaches the day in front, so the cards never touch or overlap, and the days sit close — a fifth of a card apart, whatever the window's height. Today starts at the middle of the window; the days before it climb the upper half. Pressing ⌘1 then ⌘2 no longer leaves both sidebar rows lit.
- The self-photographing mode (used to check layout without anyone at the Mac) now asks the window server for the app's own window only, so macOS no longer treats each picture as screen recording and says so; the store pictures keep the fuller composite by request.
- **Float on top.** ⌘. (View → Float on Top) keeps the window over other apps' windows and on screen across Stage Manager sets; a pin in the footer shows while it floats. Remembered between launches.
- This documentation site, at [docs.glassine.ink](https://docs.glassine.ink), and the front door at [glassine.ink](https://glassine.ink).
- App Store build 0.2.3 (7), with all of the above, submitted for review in answer to App Review's request for information about the first build.
- *After build 7.* **Formatting as you go.** A bar appears over selected text — bold, italic, strike, code, chip, link, H1–H3, bullet, numbered, task, quote — and acts on every paragraph a selection touches. A `/` at the start of a line opens a menu of headings, lists, task, quote, code block, divider, link, chip and dates, filtered by what you type after it. **Chips**: ⌘⇧H puts the selected words in a capsule like a date's, written as `==word==`, drawn in Review and the PDF too. **Hide Markdown syntax** (⌃⌘M, View menu, Settings → Editor) takes the marks off the page except in the sentence being written; bullets draw as bullets. See [formatting](/editor/formatting). The caret's glide time now goes up to 500 ms.
- *After build 7.* Sorting by **date created** works: every save used to put a new file in the old one's place, which made a document's creation date its last save, so the order was the same as *Last edited*. Saves now carry the creation date across. Documents already in the library keep the dates they have, which is when they were last saved before this build; new ones and everything from here on are right.
- *After build 7.* **Settings, remade.** A rail of sections down the left — Library; Type, Caret, Modes, Typing; Theme, Behind the glass; About — each fitting its page, drawn in the theme's own colours rather than the system's grouped form: panels of rows, sliders and pill pickers in the accent, tiles for the themes and the backdrops with the chosen one ringed in its accent. A search box at the top of the rail finds any setting by name — the rail keeps the sections that have something, the card turns to the first, and the rows that match light up; ⌘F goes there, Esc clears it. The Type section shows a piece of page set in the current type, and the Caret section a line with the caret gliding along it, blinking and shaped as it is set, hopping when the tricks are on. A row that is not at its default shows ↺ under the pointer, to put that one back. About holds the version, the updater, links to the manual and the source, and *Restore defaults*, which ⌘Z takes back. Settings reopens on the section it was closed on. See [settings](/reference/settings).
- *After build 7.* **Open With.** Glassine registers as an editor of Markdown and plain-text files, so Finder's Open With lists it and Get Info → Change All… can make it the default for `.md` (or `.txt`). A file from outside the library opens in place — edited and saved where it is, never copied in — under an *Elsewhere* row in the sidebar; File → Add to Library copies it in. File → Open… (⌘O) opens any such file. See [files from elsewhere](/library/files#files-from-elsewhere).
- *After build 7.* **The editor no longer goes deaf for a few seconds** after being left alone or after a trip to another window with a backdrop showing. The backdrop's frames were drawn on the main thread, and asking the graphics system for the next frame can block for up to a second whenever the window server is not taking frames — the display dimmed, the window on another Space, a switch between apps — twenty times a second. The frames are drawn on a queue of their own now; the main thread never waits.
- *After build 7.* **Backdrops of your own, and more colour in the built-in ones.** The backdrops moved from General to Settings → Themes → *Behind the glass*, laid out like the themes: a list, and the selected one's colours beside it. Press + to copy any set into one of yours and change its three to five colours; the theme still sets the lightness, so it stays readable. Three new sets — Nebula, Borealis, Sunset — and the old ones now run through more than one colour: the folds run round the set as a ramp, so every colour in it is on screen at once with folds of its own. Frost is gentler at the low end and goes all the way at the top, so the whole slider is usable, and a **paper grain** slider of the backdrop's own sits beside it. Drift runs at about a third of its first speed: it had been moving enough to catch the eye. The switch between the two halves of the pane, and the appearance controls, sit centred; Settings reopens on the half it was closed on. See [behind the glass](/appearance/backdrop).
- *After build 7.* **Caret tricks.** Left alone for a few seconds the caret does a trick — a hop, a bounce, a flip, a wiggle, a stretch, a lean — and another every several seconds until you type; every shape performs. (The first came after seven to twelve seconds in 0.2.5 and 0.2.6, late enough that most people would never see one; it comes after two and a half to four now.) Settings → Editor → Caret → *Tricks when idle* turns them off. And when typing carries the caret to the next line — a word wrapping, a Return — its glide takes a quarter longer, so the long way back to the left reads as one motion. See [the caret](/editor/caret#tricks).
- *After build 7.* **⌘Z in Settings** takes back the last change to a setting, from any pane, the View menu or the command bar, and ⇧⌘Z puts it back; a slider dragged or a colour picked is one step. Edits to custom themes are on the same stack.
- *After build 7.* **The Edit menu is back**, and with it ⌘A, ⌘Z, ⌘X, ⌘C and ⌘V in the editor, and ⌘Q, ⌘H, ⌘W and ⌘M. The Window → Glassine item added for App Review had been put in by taking the scene's standard menus away, which took those too. In build 11 of the direct download and build 10 of the store version only; the update puts them back.
- *After build 7.* **Backdrops.** The glass can look through folds of colour inside the window instead of the desktop — long, deep, slowly moving, like silk lit from one side, drawn by a small shader on the graphics processor — in the theme's own colours (Aurora) or one of six palettes, with drift and frost to taste, for a desk without a wallpaper worth looking through. Built dark first, so pale text stays readable over every part of it. Settings → General → Behind the glass, View → Backdrop, or ⌘K. See [behind the glass](/appearance/backdrop).
- *After build 7.* **A dark icon.** When the Mac is in dark mode the Dock and the app switcher show the same sheet at night — charcoal, the g in paper-white — and the paper icon by day; it changes with the appearance. Finder and Launchpad, which read the icon file, keep the paper one. `Resources/make_icon.py --dark` draws it from the same geometry.
- *After build 7.* **Window → Glassine** brings the window back after it has been closed, as does any menu command that needs it (⌘N, ⌘1, ⌘2, ⌘F, ⌘,); clicking the Dock icon already did. The permission prompts for iCloud Drive and the Documents folder now say what Glassine does with the folder, with an example. Both asked for by App Review.
- *After build 7.* The gear at the bottom of the sidebar opens Settings again. It had been asking for a Settings window the app stopped having when Settings became an overlay, and so did nothing; ⌘, and the menu were unaffected.
- *After build 7.* Esc from the ⌘F search glides the field back to its spot in the header, on the same spring that brought it out; it used to cut straight back.
- *After build 7.* The direct download updates itself. Sparkle checks a feed at glassine.ink once a day, and a new version is offered, downloaded, checked against its signature and installed in place; Help → Check for Updates… asks now. Settings → General turns the daily check off. The App Store version is built without it — the store is its updater.
- *After build 7.* In Review, ⇥ and ⇧⇥ walk the six styles, next and previous.
- *After build 7.* ⌘⇧S is a second key for Review, beside ⌘↩ — ⌘S shows the sidebar, so the shifted key sits under the same finger.
- *After build 7.* ⌘1, ⌘P and the sidebar's All Documents row only ever show All Documents. They used to close it when pressed again, which dropped you into whatever document was last open — easy to hit while switching between Timelapse and All Documents. Esc is the way back to a document.
- *After build 7.* Esc from a note opened out of Timelapse returns to Timelapse — the page shrinking back into its day — rather than to All Documents.
- *After build 7.* **Caret shapes.** Settings → Editor → Caret has a row of eight to pick from, each drawn as it will look: Bar, Pin, Serif, Wedge, Ghost, Comet, Glow and Hollow. All of them glide, blink and take the width and colour the same way. See [the caret](/editor/caret#shapes).
- *After build 7.* Three hyphens on a line draw as a horizontal rule — a line across the middle of the column — instead of sitting there as dashes, and smart dashes no longer turn them into an em dash and a hyphen on the way. The dashes come back while the caret is on that line.
- *After build 7.* A sixth Review style, **Book Dark**: the Book page after dark — warm charcoal paper, cream type, a terracotta drop cap and ornaments. Both Book pages have slightly softer corners.
- *After build 7.* Capsules — dates and chips — stand a full space clear of the words around them; they used to swallow the space and touch. They also hug the type now rather than the whole line, so a short word gets a pill rather than an egg, and one that starts a line keeps its rounded left edge. In Review's Book styles a capsule no longer inherits the paragraph's first-line indent, which had been pushing its word to the right inside it.
- *After build 7.* **Paragraph indent**, in Settings → Editor: the first line of each body paragraph steps in by up to three ems; headings, lists and quotes keep their own margins. The caret's settings moved into the Editor pane, under *Caret*, so Settings has three panes rather than four.
- *After build 7.* ⌘B, ⌘I, ⌘E, ⌘⇧X and ⌘⇧H turn their mark off the way a rich-text key does: at the end of a run the caret steps out past the closing mark instead of opening a second, empty pair; in the middle the run splits; with the words selected the marks come off.
- *After build 7.* Typing a heading in typewriter mode no longer makes the line bob. Each keystroke arrived in the body size and was enlarged a moment later; the view was centred on the line twice, once for each, and the two disagreed by a few points. The typing attributes now follow the styling, and the line is centred once, from the text as it is drawn.
</Update>

<Update label="September 4, 2026">
- **Motion.** Checking a task sweeps the strike across the words over half a second while they fade to the muted colour, with a pulse on the box; the sink a moment later fades out, moves and fades back in; unchecking brightens the words back. Review does the same in CSS. And twenty smaller things: focus mode crossfades between paragraphs, settles when turned on and lifts gradually; date capsules and pasted links pulse; sidebar rows slide; stars spring; every count ticks; the search field brightens with focus; a folder's count and its + trade places on hover; the Saved mark springs in; cards cascade in and lift on hover; Review scales in; the command bar highlight glides; Settings tabs crossfade. All of it steps aside under Reduce Motion. See [small delights](/reference/small-delights).
- New installs start in **Helvetica Neue**.
- **Focus mode keeps Markdown styling** in the dimmed text — darker and less saturated rather than flattened to grey.
- **Leaving a document shrinks the page back into its card**, the reverse of the way it opened.
- Two more built-in themes, **Dusk** and **Lavender**; Dusk is the new default and the dark half of the system pair.
- The sidebar's **Documents** tree starts collapsed, with a count; All Documents is the better way to browse.
</Update>

<Update label="September 3, 2026">
- **The Shelf.** Shelve a document or folder (right-click, ⌘⇧⌫, or ⌘K) and it leaves Recents, Starred, the tree and All Documents for a collapsed Shelf section at the bottom of the sidebar, still searchable; Unshelve puts it back where it was. On disk, a plain move into a `Shelf` folder that mirrors the original path.
- **Scrolling lifts focus mode**; the next click or keystroke brings it back where the caret lands.
- **Paste a link over words to link them**: with a web address on the clipboard, ⌘V over a selection makes `[words](url)` instead of replacing the words.
- A day's note keeps its date as its name whatever its heading says, and only date-named notes appear in the Timelapse corridor.
- A new icon: the wordmark's lowercase *g* on paper, ruled lines fading in from the left.
- The window reopens at the size and position you left it.
- Review works in the sandboxed App Store build (the web view needs the outgoing-connection entitlement to start).
- The app photographs itself for the store screenshots; no permissions, no one at the keyboard.
- App Store build 0.2.3 (6) submitted for review.
</Update>

<Update label="September 2, 2026">
- **Nested lists.** Tab and Shift-Tab nest and un-nest bullets, numbers and tasks; numbered items renumber; Return on an empty nested item steps out.
- **Headings centered** by default, in the editor and Review, with a switch.
- **Finished tasks sink** below the unfinished ones after a moment, nested items in tow, and rise back home when unchecked. On by default, with a switch.
- **Drag a task box, a bullet or a number** to reorder a list.
- A steadier sidebar resize.
- **Undo for almost everything**: after the editor's own undo runs out, ⌘Z reaches file operations — a new document, a rename, a move, a duplicate, a trash.
- Settings became a taller card with room to breathe; the Themes pane scrolls; Tab cycles the panes.
- A hand-made wordmark in the sidebar header.
- The App Store flavor: sandbox, an iCloud container of its own, bookmarked custom folders, and the packaging scripts. A privacy policy.
</Update>

<Update label="September 1, 2026">
- **Ocean** became the default look, then a set of first-install defaults tuned for writing: typewriter and focus on, a soft 4 pt caret.
- **The ⌘K command bar**, listing what applies where you are.
- **Search that glides** from the header to the middle of the window on ⌘F, and searches full text.
- **The Daily timeline** — later Timelapse — as a receding corridor, with ⌘D for the view and ⌥⌘D for today's note.
- Quiet chrome while typing; the ⌘/ shortcut sheet; themes that follow the system; the *Start writing* placeholder; daily notes; PDF export; the card that grows into the page.
- Faster launch: the library is listed without reading a file, and previews, tags and search text arrive on a background queue.
- Gradient strikes, lit capsules, softer edges. Click a task's `[ ]` to check it, in the editor and in Review.
- Documents open with the caret at the end.
</Update>
