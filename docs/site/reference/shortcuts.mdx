Inside the app, ⌘/ opens a translucent sheet with the shortcuts on it; Esc, ⌘/ again, or a click outside closes it. ⌘K opens a command bar listing what applies where you are, each with its key.

## Around the app

| Keys | What it does |
|---|---|
| ⌘1 or ⌘P | All Documents — the mosaic of the whole library. Pressed again, back to the document |
| ⌘2 or ⌘D | Timelapse — today's note in front, earlier days receding behind it |
| ⌘3 or ⌘N | New document |
| ⌘K | The command bar |
| ⌘F | Search the library — titles, tags and full text |
| ⌘S or ⌘\ | Show or hide the sidebar |
| ⌘↩ | Review — the document rendered read-only in a chosen style. Again, or Esc, to leave |
| Esc | Step back one level: Review → editor → All Documents, the page shrinking into its card. In All Documents, Esc clears a search or tag filter first, then returns to the open document |
| ↑ ↓ ← → and ↩ | In All Documents: move between cards and open the selected one. ⌘↩ opens it in Review |
| ⌘. | Float on top — the window stays over other apps' windows and stays on screen when Stage Manager switches to another app. Again to stop |
| ⌘, | Settings. Inside it, ⇥ and ⇧⇥ cycle the panes; Esc closes |
| ⌘/ | The shortcut sheet |
| ⌘+ ⌘− ⌘0 | Text size — the editor's, or Review's while a page is showing |
| ⌃⌘T | Typewriter scrolling |
| ⌃⌘F | Focus mode |

⌘1, ⌘2 and ⌘3 match the three rows at the top of the sidebar, in order, so the left hand can reach them while the right is on the mouse.

## Documents

| Keys | What it does |
|---|---|
| ⌘N / ⌘⇧N | New document / new folder |
| ⌥⌘D | Today's note, in the Daily folder, created on first use |
| ⌘R | Rename |
| ⌘⇧⌫ | Shelve — out of the sidebar, Recents and All Documents, into the Shelf. Again to unshelve |
| ⌘⌫ | Move to Trash |
| ⌘Z / ⇧⌘Z | Undo and redo — typing first, then file operations: a new document, a rename, a move, a duplicate, a shelving, a trip to the Trash |
| ⌘⇧E | Export as PDF, in the current Review style |
| ⌘⇧C / ⌥⌘C | Copy the whole document as Markdown / as rich text |
| ⌘⇧R | Reveal the document in Finder |

Save Now, Duplicate and Reveal Library in Finder are in the File menu without keys; Duplicate is in every right-click menu too.

## Writing

| Keys | What it does |
|---|---|
| ⌘B ⌘I | Bold, italic |
| ⌘E | Inline code |
| ⌘⇧X | Strikethrough |
| ⌘⇧K | Link — wraps the selection; uses a web address from the clipboard if there is one |
| ⌘V over a selection | With a web address on the clipboard, links the selected words instead of replacing them |
| ⌘⌥1 ⌘⌥2 ⌘⌥3 | Heading level (the same level again turns it back into body text) |
| ⌘⌥0 | Body text |
| ⌘⇧L | Toggle a task checkbox; makes the line a task if it is not one |
| ⇥ / ⇧⇥ | Nest or un-nest a list item — bullets, numbers and tasks |
| ↩ | In a list, the next item; on an empty item, the end of the list (or one level out, if nested) |
| ⌘⇧F | Find in the open document; ⌘G next match, ⌘⇧G previous |
| `@today` `@tomorrow` `@yesterday` + space | The date, as a capsule |

## With the mouse

- Click a task's box to check it; click again to reopen it. Works in Review as well.
- Drag a task box, a bullet or a list number up or down to reorder the list.
- Click a tag in the sidebar to filter by it; the ⓧ beside its name clears the filter.
- Hover a folder in the sidebar for a **+** that makes a document inside it.
- Right-click a document, a folder or a card for the full menu.
- Click a card in All Documents or in Timelapse to open it.
- Scroll in Timelapse to walk back through the days.
- Scroll in the editor to lift focus mode; click or type to bring it back.
- Click the copy button at the bottom-right of the editor for Markdown; click and hold for rich text.

## What is deliberately not there

⌘S does not save, because nothing needs saving; it hides the sidebar. ⌘X is Cut, as everywhere on the Mac. ⌘⇧D is left alone, since many people bind it system-wide.
