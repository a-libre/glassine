## ⌘K

A small translucent bar with a field that says *Type a command*. Type to filter, ↑ and ↓ to move, Return to run, Esc to close. The highlight glides between rows rather than jumping.

What it lists depends on where you are. Every command shows its key beside it, so the bar doubles as a way to learn the shortcuts you use most.

**In the editor:** All Documents, Review, Today's Note, Timelapse, New Document, turn typewriter scrolling on or off, turn focus mode on or off, Copy as Markdown, Copy as Rich Text, Export as PDF…, Shelve or Unshelve, Search.

**In Review:** the five Review styles, with a ✓ on the current one; Leave Review; Copy as Markdown; Copy as Rich Text; Export as PDF…; All Documents.

**In All Documents or Timelapse:** New Document, Today's Note, Timelapse (or All Documents, whichever you are not in), Sort by last edited / name / date created with a ✓ on the current sort, Search, and Back to Document when one is open.

**Everywhere, at the bottom:** every theme as *Theme: …* with a ✓ on the current one, Float over other windows (or Stop floating), Settings…, and Shortcuts.

## ⌘/

The shortcut sheet: every key on one card in the app's own type, grouped into Documents, Around the app, Writing, and Copy & view. Esc, ⌘/ again or a click outside closes it. The [shortcuts page](/reference/shortcuts) is the same list with more words.
