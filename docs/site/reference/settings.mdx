⌘, or Glassine → Settings…, or the gear at the bottom of the sidebar. Settings open as a card over the window rather than in a window of their own, so everything you change is visible behind it as you change it. ⇥ and ⇧⇥ move between the four panes; Esc closes the card.

## General

**Library**

| Setting |  |
|---|---|
| Location | Where the library is, with *Reveal in Finder*, *Change…* to pick another folder, and *Use iCloud Drive* to return to the default. A line beneath says whether the folder syncs. |

**Files**

| Setting | Default | |
|---|---|---|
| Name files after the first line | On | New documents take their file name from their first line as you write. Renaming a file yourself pins its name. |
| Sort documents by | Last edited | Or *Name*, or *Date created*. Applies to the sidebar and All Documents. |

**Saving** — a note that nothing needs saving: changes are written about half a second after you stop typing and at least every few seconds while you type.

**Updates** — in the direct version, *Check for new versions once a day* (on) and the version you are running. The App Store version shows its version and says updates arrive through the App Store.

## Caret

**Movement**

| Setting | Default | Range |
|---|---|---|
| Smooth movement | On | |
| Glide time | 270 ms | 40–300 |
| Smooth while typing | On | Off: the caret glides for arrow keys and clicks but snaps as you type |

**Look**

| Setting | Default | |
|---|---|---|
| Blink | Soft | Or *Classic*, or *Never* |
| Width | 4 pt | 1–4 in half-point steps |

The caret uses the theme's caret colour, usually the accent. Reduce Motion in System Settings disables gliding.

## Themes

| Setting | Default | |
|---|---|---|
| Appearance | Always the chosen theme | Or *Follow the system*, which reveals a *Light* and a *Dark* picker |
| Light | Paper | Used when macOS is in light mode and the appearance follows the system |
| Dark | Dusk | The same, for dark mode |

Below that, the list of themes — *Built in* and *Mine* — with **+** to duplicate the selected theme into one you can edit, **−** to delete one of yours, and a ••• menu with *Import Theme…* and *Export "…"*. Selecting a theme of your own opens its editor beneath: name, dark appearance, glass material, tint, tint strength, paper grain, sidebar tint, and the nine colours. The [themes page](/appearance/themes) walks through it.

## Not in Settings

A few things are remembered without a switch here: whether the window floats on top (⌘.), the sidebar's width and whether it is showing, which folders are expanded, the six most recent documents, starred documents, the window's size and position, the Review style and its text scale, and the last document open, which reopens at launch.
