# Marks on the Page

#glassine #markdown

Everything Glassine draws is plain Markdown underneath: a text file, readable anywhere, with the marks either showing or stepping out of the way.

## The small ones

Words can be *leaned on*, **pressed**, ~~taken back~~ or set in `code`. A few can be put in a ==chip==, and a date typed as @today becomes @{{TOKEN}} — a capsule here, plain text everywhere else.

## The lines

1. A numbered list, for things in order
2. A second thing
3. A third, and the numbers keep themselves right

- A bulleted list, for things that are not
- [ ] A task, waiting
- [x] A task, done, and sinking to the bottom

> A quotation stands a little apart, with a line down its side.

```
// A block of code keeps its own shape
let page = Glass(words: text)
```

---

A rule across the page marks a change of subject. Below it, a [link](https://glassine.ink) to the website, underlined only when you look.

## Hiding them

⌃⌘M takes the marks off the page except in the sentence being written. Nothing about the file changes — only what is drawn.
