A quiet place to write.

Glassine is a Markdown writing app for the Mac. A window of translucent glass, a caret that glides instead of jumps, and files that are plain text — in iCloud Drive, or a private GitHub repository — saved as you type, yours to keep.

Version 0.2.14 — free, open source, macOS 14 or later. The store copy is called Glassine Writer; the .dmg updates itself.

What it is

Fewer features than most writing apps, and fewer interruptions. Everything it does is on one screen or one key away.

Two Macs, no iCloud required

iCloud Drive is the simple way to have the same documents on every Mac. For a Mac you'd rather not sign into iCloud on — a work laptop, say — Glassine can keep the library in a private GitHub repository of yours instead.

A token for that one repository, and nothing else about your accounts touches the machine. Every round of changes is a commit, so the repository holds every version of every note; no git to install, no background process. Settings → Library → Sync, and the manual page walks through it.

And the rest

  • Focus mode and typewriter scrolling. The paragraph you are writing stays put and lit; the rest steps back, Markdown styling intact.
  • Formatting as you go. Select words and a bar appears over them — bold, italic, strike, code, chip, link, headings, lists, a task, a quote. / at the start of a line opens a menu of the same; keep typing to filter.
  • Themes. Nine built in, dark by default and a few light ones; make your own with live preview, and import or export them as files.
  • A caret that glides. Speed, blink, width and shape — eight of them — are yours to set. Left alone a few seconds it does a trick: a hop, a bounce, a flip. Off under Reduce Motion.
  • A library, not a file picker. Plain .md files and folders in iCloud Drive, or any folder you point it at, named from the first line as you write.
  • Open With. Finder can open .md and .txt files in Glassine; a file from outside the library is edited where it is and never copied in.
  • Autosave that never asks. Half a second after you stop typing, and every few seconds while you keep going.
  • Tasks that behave. Click a box; the strike sweeps across; a moment later the item settles below the unfinished ones.
  • Dates as you type. @today becomes the date, drawn as a capsule, kept as text.
  • Markdown, lightly styled — or hidden. The marks step back, or leave the page altogether except in the sentence being written; the file is the same plain text either way.
  • Chips. ⌘⇧H puts a word in a capsule, like a date's. In the file it is ==this==, which other editors read too.
  • Float on top. ⌘. keeps the window over everything else, Stage Manager included.
  • One key away. ⌘K is a command bar for everything; ⌘1 ⌘2 ⌘3 are All Documents, Timelapse and a new page; ⌘/ shows every shortcut on one sheet.
  • Nothing sent anywhere. No accounts, no analytics, no servers. The privacy page is one paragraph.

What's new

Version 0.2.14 — September 17, 2026. The changelog has every line, by day.

  • A Welcome page for the app as it is. The document a first launch opens now tours the backdrop behind the page, the bar over a selection and the slash menu, chips, hiding the syntax, Timelapse, the command bar, Review, Settings and sync — with every key checked. And it opens from its heading, not its end.
  • Aurora from the first launch. A new copy opens with folds of the theme's own colours behind the glass, the way the pictures look; the desktop's blur is a tile away.
  • Sync with GitHub. The library kept in a private repository of yours, for a second Mac you'd rather not sign into iCloud on — and a history of every note, every version. No git, no daemon; connect with a token in Settings → Library. How it works.
  • Settings, remade. A rail of sections, a search box that finds any setting by name, ⌘Z to take a change back, and the Type and Caret sections showing what they do before you look behind the card.
  • Caret tricks. Left alone for a few seconds, the caret hops, bounces, flips, wiggles, stretches or leans — every shape performs. Off in a switch, and under Reduce Motion.
  • On the Mac App Store, as Glassine Writer. The direct download stays, and updates itself.

Get it

Requires macOS 14 or later. Free, open source, MIT.

Mac App Store NOW

Glassine Writer — the plain name was already reserved there; the app itself is Glassine everywhere. Free. Updates come through the store.

Direct download NOW

Glassine.dmg — notarized, drag to Applications. It checks for a new version once a day and installs it itself. Every version is under Releases on GitHub.

Build from source NOW

Xcode's tools, three lines, a minute.

git clone https://github.com/a-libre/glassine
cd glassine
./build.sh --install

Support

The manual covers every feature, key and setting. For a bug or a question, open an issue on GitHub; Help → Copy Debug Info in the app puts everything useful on your clipboard to paste in.
